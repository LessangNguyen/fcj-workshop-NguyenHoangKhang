This section provides an overview of the technical blogs I have written and published during my learning journey in **Amazon Web Services (AWS)**. These articles focus on cloud computing services, system architecture, data processing, and the practical applications of cloud technologies.

The articles are shared with the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community to summarize technical knowledge, share learning experiences, and explore different services within the AWS ecosystem.

### [Blog 1 - AWS LAMBDA + SQS: UNDERSTANDING BATCH RETRY BEHAVIOR](3.1-Blog1/)

This article explores how AWS Lambda processes messages from Amazon SQS through batch processing. It focuses on scenarios where one message in a batch fails, explaining how Lambda handles retries, how failures affect other messages, and what developers should consider when designing asynchronous processing systems. The article provides a better understanding of Lambda and SQS integration and highlights approaches to building more reliable, fault-tolerant applications.

### [Blog 2 - AWS HEALTHIMAGING: MANAGING MEDICAL IMAGING DATA AT SCALE](3.2-Blog2/)

This article introduces AWS HealthImaging, a cloud-based service designed to store, process, and share medical imaging data. It covers how the service manages DICOM data and supports scalable storage and retrieval of medical images. The article also highlights how cloud technology can help healthcare organizations build flexible, scalable, and secure medical imaging management systems.

### [Blog 3 - AMAZON DOCUMENTDB: A FULLY MANAGED DOCUMENT DATABASE SERVICE](3.3-Blog3/)

This article introduces Amazon DocumentDB, a fully managed document database service designed for applications using MongoDB-compatible workloads. It explores the service's architecture, scalability, storage and replication mechanisms, high availability, backup capabilities, and security features. The article provides an overview of how Amazon DocumentDB supports the deployment and management of document-based applications on AWS.
